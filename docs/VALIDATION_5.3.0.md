# 5.3.0 验收记录（2026-10-10）

改动：寄存器监视窗口「导出数据」与主工作台「导出快照」支持无损压缩 ZIP（内含同名 CSV，解压后与普通 CSV 逐字节一致）或普通 CSV 导出，默认 ZIP；导出按文件名扩展名识别格式，先写临时文件、成功后再替换目标文件。应用版本和 Windows 文件/产品版本统一为 5.3.0，固定版本资源为 5.3.0.0。

## 最终验证

执行 `tools/build.py`，完整构建 115 秒。

| 项目 | 结果 |

| 单 EXE 隔离验收 | 113 项通过；首次解压及验收 8.5 s，损坏缓存自动修复及验收 7.0 s；陈旧缓存自动清理 |
