# 5.3.9 验收记录（2026-10-11）

改动：在线升级流程强化（升级助手 FullLanguage 检测与启动确认、新版 EXE 启动确认与失败回滚、替换重试、残留清理与结果读取接口就绪）；SSH 会话更健壮（命令超时/取消以 Ctrl+C 中断并保留会话、连接被拒明确提示、dropbear 主机密钥备份收敛到最近 5 份、无提示符 shell）；寄存器监视增强（60 秒无数据自动停止、板端时钟倒退容忍、无 `%N` 时钟按间隔铺开、截断点补齐、sleep 三档降级）；寄存器解析增强（十进制/纯数字 define 与重复定义告警、if 式写与高位填充拼接、读 mux 外触发寄存器标记 `read_side_effect` 永不自动读、`imported_at` 记录导入时间）；界面改进（IP 地址点号跳格/整段粘贴/去前导零/完整校验、上传回退确认前后校验连接、模态框期间暂停自动读取、串口按钮兼作取消）；top 解析（块注释后代码保持有效、单行实例优先于注释模板）；bit 打包健壮性（网络共享短读容错、多条清理警告累积、junction 跳过）；构建与发布（单文件 EXE 可重现构建、发布脚本校验 EXE 版本一致、并行步骤失败联动取消）。应用版本和 Windows 文件/产品版本统一为 5.3.9，固定版本资源为 5.3.9.0。

首轮构建测试步骤发现两条与本次改动相关的旧测试未同步，均为测试桩问题而非功能缺陷：① 新增的「回退备份同名秒冲突避让」在测试桩 `stat` 恒返回存在时无限循环（真实板端对不存在的文件会抛错，循环正常退出）；② `DemoSession.remote_root` 改为惰性创建后，旧测试在构造时断言模拟板端目录存在。两条测试已按新行为修正（未改动任何功能性代码），复跑与全量重跑均通过。本次验证使用离线模拟会话，未在实机窗口复测。
